# Root Finding Methods in Python

This repository contains Python programs for solving nonlinear equations using different numerical root-finding methods.

## Methods Included
- Bisection Method
- False Position (Regula Falsi) Method
- Newton-Raphson Method
- Secant Method
- Fixed-Point Iteration Method

## Purpose
The goal of this project is to understand and implement numerical methods for finding approximate roots of equations using Python.

## Language
- Python

## Applications
These methods are useful in numerical analysis, mathematics, and engineering to find approximate solutions to nonlinear equations.
